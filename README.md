# PACE-PDR
# 一个基于Android 的行人航位推算（PDR, Pedestrian Dead Reckoning）实验项目。  
# 项目利用手机内置的加速度计、陀螺仪、磁力计和 GPS 等传感器，实现步态检测、步长估计、姿态解算、航向修正与轨迹推算，并支持实时运行、离线回放和结果评估。

# 项目简介
# PDR_Zjj 是一个面向手机端的 PDR 实验平台，目标是构建从传感器数据采集、多传感器预处理、姿态估计、步态检测、步长估计、位置更新到轨迹可视化与误差评估的完整流程。
# 项目不仅支持实时采集与在线定位，还支持导入历史原始数据进行离线回放，并可结合 GPS 真值轨迹对 PDR 结果进行对比分析。因此，本项目既可以作为一个可运行的 Android 应用，也适合作为：


## 主要功能
- 基于 Android 手机内置传感器实现 PDR
- 实时采集加速度计、陀螺仪、磁力计和 GPS 数据
- 支持多传感器时间同步、插值与滑动平均预处理
- 支持 6DOF / 9DOF Mahony AHRS 姿态解算
- 支持步态检测与步长估计
- 支持航向修正与按步位置递推
- 支持实时轨迹显示
- 支持离线原始数据导入与轨迹回放
- 支持 PDR 与 GPS 轨迹对比评估
- 支持实验数据保存、参数配置与结果导出


## 系统流程

   ↓

   ↓
初始化（姿态 / 初始位置）
   ↓
AHRS 姿态解算
   ↓
步态检测
   ↓
步长估计
   ↓
航向修正
   ↓

   ↓
